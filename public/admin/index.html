WhatsApp

One workflow, two ways to send. Automatic: messages go out through the WhatsApp API by themselves, and patients and centres can use the WhatsApp menus. Manual: you send each message from here with WhatsApp, exactly as before. If the API fails, the message shows as Not sent in that person's chat in Inbox, with Send by hand.

Message texts

Used for both automatic and manual sending. {{name}} etc. are filled in from the booking. A line whose values are all empty is left out. To message someone who hasn't written to us in 24 hours, WhatsApp needs to approve the text first – press Send for approval (takes minutes to a day).
